next-gen-scrapy analytics API

Free, no-auth access to every pass, route and carry recovered from NFL Next Gen Stats chart images, matched to its real play-by-play + FTN charting row - so every play feature (down, distance, EPA, WP, coverage, play-action, ...) is filterable and exportable alongside the chart's own recovered field coordinates.

Endpoints

EndpointGrain
GET /passesone row per pass, matched to its pbp play
GET /routesone row per route (full traced path), matched to its pbp play
GET /carriesone row per carry (full traced path), matched to its pbp play
GET /<table>/fieldscolumn metadata (name, type, distinct values) for building filters
GET /<table>/distinctdistinct values of ?columns=a,b under any filters (e.g. weeks in a season)
GET /<table>/heatmapsmoothed density grid of every matching play (same filters; mode=path|end, smooth= yards)
GET /filters?dataset=the curated filters (label, group, control type, choices / range)
GET /ask?q=plain-English question → dataset, season, weeks, player and filter params

Filtering

Every column on every endpoint is filterable - chart columns and pbp/FTN columns alike:

?season=2024&team=BUF&pass_type=TOUCHDOWN     exact match
?epa__gte=1&air_yards__lte=10                 range (__gte / __lte / __gt / __lt / __ne)
?week__in=1,2,3                               any of several values
&is_play_action=true                          booleans as true/false

Examples

curl "http://127.0.0.1:8000/passes?season=2024&team=BUF&pass_type=TOUCHDOWN"

curl "http://127.0.0.1:8000/routes?name=Justin+Jefferson&is_play_action=true&format=csv" -o jj_pa_routes.csv

All endpoints accept limit (default 500, max 5000), offset and sort (e.g. sort=-epa) for pagination, and format=csv to export instead of JSON.
